IMPORTANT BEFORE PUBLISHING
1. Open index.html and replace YOUR_EMAIL@example.com in the contact button with an email address you control.
2. The supplied spreadsheet screenshots include customer names, phone numbers, address/booking identifiers. Replace them with redacted or dummy-data screenshots before making the site public.
3. This is a static website. The spreadsheet screenshots are illustrative images, not a live sheet integration.
4. The MP3s are web-call demos, not proof of a live public phone number.

LOCAL TEST
- Keep index.html and the assets folder together.
- Open index.html in a modern browser. Audio should play directly from the supplied MP3 files.
- For best testing, use a simple local static server or deploy to GitHub Pages.

GITHUB PAGES
1. Create a GitHub repository.
2. Upload index.html and the complete assets folder (preserve exact names and folder structure).
3. In repository Settings > Pages, choose Deploy from a branch.
4. Select the main branch and /(root), then Save.
5. Wait for the Pages URL to appear and open it on desktop and mobile.
6. Test both audio tabs, transcript seeking, image zoom, navigation and the contact link.

CONTACT FORM
The CTA uses a mailto link, not a database or lead-storage form. The visitor's email app opens a prepared email. It will only work correctly after you add your real contact email.
